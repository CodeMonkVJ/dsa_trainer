# Pascal's Triangle

Return the first `numRows` rows of Pascal's Triangle. Each row starts and
ends with `1`; every interior value is the sum of the two values above it.

Implement this function:

```cpp
std::vector<std::vector<int>> generatePascal(int numRows);
```

Return an empty vector when `numRows <= 0`. Preserve row order from the top
of the triangle downward.
