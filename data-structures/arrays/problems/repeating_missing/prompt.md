# Repeating and Missing

Implement `pair<int, int> findRepeatingMissing(const vector<int>& values)`.

The input has length `n` and contains values from `1` through `n`: exactly one
value appears twice and exactly one value is absent. Return `{repeating,
missing}` in that order. Do not modify the input.

Target `O(n)` time and `O(1)` auxiliary space. Use a wide integer type for
intermediate arithmetic.
