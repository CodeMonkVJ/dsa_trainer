# Set Matrix Zeros

Given a rectangular integer matrix, if any cell is `0`, set every value in
that cell's row and column to `0`. Modify the matrix in place.

Implement this function:

```cpp
void setZeroes(std::vector<std::vector<int>>& matrix);
```

Use `O(1)` auxiliary space apart from the matrix itself. An empty matrix is
valid and should remain unchanged.
