# Find Duplicate

Implement `int findDuplicate(const vector<int>& values)`.

The input contains `n + 1` integers, each in the range `[1, n]`, and exactly
one value occurs at least twice. Return that repeated value. Do not modify the
input, do not sort it, and use `O(1)` auxiliary space.

Target `O(n)` time. The input always satisfies the stated constraints.
