# Remove Duplicates From Sorted Array

Implement:

```cpp
int removeDuplicatesSorted(std::vector<int>& nums);
```

`nums` is sorted in nondecreasing order. Modify it in place so the first `k`
elements contain each distinct value once, in sorted order, and return `k`.
The contents after index `k - 1` are irrelevant. Return `0` for an empty input
and use `O(1)` extra space.
