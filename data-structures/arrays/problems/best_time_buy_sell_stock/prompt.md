# Best Time to Buy and Sell Stock

Given daily stock prices, choose one day to buy and a later day to sell to
maximize profit. You may complete at most one transaction. If no profitable
transaction exists, return `0`.

Implement this function:

```cpp
int maxProfit(const std::vector<int>& prices);
```

Return `0` for an empty or one-day input. Aim for `O(n)` time and `O(1)` extra
space.
