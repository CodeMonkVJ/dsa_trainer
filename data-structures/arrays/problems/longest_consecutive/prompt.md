# Longest Consecutive Sequence

Implement:

```cpp
int longestConsecutive(const std::vector<int>& nums);
```

Return the length of the longest sequence of consecutive integer values in
`nums`. Values may appear more than once, and an empty input returns `0`.
The sequence need not occupy adjacent positions in the input. Aim for `O(n)`
expected time and `O(n)` extra space.
