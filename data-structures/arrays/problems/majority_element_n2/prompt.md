# Majority Element (n/2)

Implement the following function:

```cpp
int majorityElement(const std::vector<int>& nums);
```

Return the value occurring strictly more than `nums.size() / 2` times. The
input is non-empty and is guaranteed to contain such a value.

Solve it in `O(n)` time with `O(1)` extra space. Do not reorder the input.
