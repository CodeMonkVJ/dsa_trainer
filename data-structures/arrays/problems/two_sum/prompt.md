# Two Sum

Implement:

```cpp
bool twoSum(const std::vector<int>& nums, int target, int* first, int* second);
```

Return `true` and write two distinct indices `first < second` when their values
sum to `target`. Return `false` when no pair exists. Either output pointer may
be null; still return the correct boolean result. You may return any valid pair.

Aim for `O(n)` expected time and `O(n)` extra space.
