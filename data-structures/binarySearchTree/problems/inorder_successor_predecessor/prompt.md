# Inorder Successor and Predecessor in a BST

Given a binary search tree and a key, return a pair containing the inorder predecessor node and inorder successor node for that key. Either pointer is `nullptr` when the predecessor or successor does not exist.

If the key is not present, use the key's sorted insertion position: the predecessor is the greatest key smaller than it and the successor is the smallest key greater than it. Return the pair in predecessor, successor order.
