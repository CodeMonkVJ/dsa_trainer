# Largest Rectangle in Histogram

Given a histogram represented by non-negative bar heights, return the largest
area of a rectangle formed by one or more contiguous bars. The rectangle's
height is limited by its shortest bar.

Implement:

```cpp
int largestRectangleArea(const std::vector<int>& heights);
```

Return `0` for an empty histogram. Aim for `O(n)` time and `O(n)` extra space.
