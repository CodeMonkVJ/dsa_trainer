# Word Break

Given a string and a dictionary of words, determine whether the string can be segmented into one or more dictionary words. A dictionary word may be used any number of times, and the entire string must be consumed.

Implement:

```cpp
bool wordBreak(std::string s, std::vector<std::string> dictionary);
```

Return `true` for an empty string. Ignore empty dictionary entries; matching is case-sensitive.
