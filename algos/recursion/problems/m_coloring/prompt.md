# M Coloring Problem

Implement `bool graphColoring(std::vector<std::vector<int>> graph, int m)`.

The graph is represented by an adjacency matrix. Return whether its vertices can be assigned colors `1` through `m` such that adjacent vertices have different colors. The graph may be empty; reject invalid non-square matrices, non-positive color counts, self-loops, and entries other than `0` or `1`.
