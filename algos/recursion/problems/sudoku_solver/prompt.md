# Sudoku Solver

Implement `bool solveSudoku(std::vector<std::vector<char>>& board)`.

The board is a 9x9 grid. Empty cells contain `'.'`; filled cells contain digits `'1'` through `'9'`. Fill the board in place and return `true` if a valid completion exists. Return `false` for an invalid or unsolvable board. A completed board must obey Sudoku's row, column, and 3x3 sub-grid constraints.
