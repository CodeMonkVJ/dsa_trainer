# Anagrams

Given two strings, determine whether one is an anagram of the other. Anagrams contain exactly the same characters with the same frequencies, including spaces, punctuation, and letter case.

Implement:

```cpp
bool areAnagrams(const std::string& first, const std::string& second);
```

Return `true` only when the strings have equal length and equal character counts. Target `O(n)` time and `O(k)` space, where `k` is the character set size.
