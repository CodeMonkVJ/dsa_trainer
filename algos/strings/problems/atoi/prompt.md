# String to Integer (atoi)

Implement `parseAtoi` to convert the leading integer represented by a string into a signed 32-bit `int`.

Skip leading spaces, accept one optional `+` or `-`, and consume consecutive decimal digits. Stop at the first non-digit after the number. If no digits are consumed, return `0`. Clamp values outside the range `[-2147483648, 2147483647]` to the nearest limit.

Do not use `std::stoi`, `std::strtol`, or similar conversion helpers.
