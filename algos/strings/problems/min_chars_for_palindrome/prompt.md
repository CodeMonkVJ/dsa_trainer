# Minimum Characters for Palindrome

Given a string `s`, return the minimum number of characters that must be inserted at the beginning of `s` so the result is a palindrome. Inserted characters may be chosen freely; do not modify the input.

Implement:

```cpp
int minCharsForPalindrome(const std::string& s);
```

Return `0` for an already-palindromic or empty string. Target `O(n)` time and `O(n)` auxiliary space.
