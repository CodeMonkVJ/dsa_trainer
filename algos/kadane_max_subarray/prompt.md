# Kadane's Maximum Subarray

Implement `maximumSubarray` for a non-empty integer array.

Return the maximum sum together with the inclusive `left` and `right` boundaries of one optimal contiguous subarray.

Requirements:

- Handle arrays containing only negative values.
- Run in `O(n)` time and `O(1)` auxiliary space.
- Do not sort or use a quadratic subarray search.
